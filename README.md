# Ryan Scenes

Ryan Scenes 将用户照片重组为具有独立审美表达的纸像海报。当前推荐的 2.2 不设置生成前询问，以真实照片为视觉锚点，并从原图建立艺术命题、核心情绪张力和解释开放性。照片可以主导画面，也可以只保留人物、局部水面、建筑群或其他叙事局部；照片与插画均不使用固定面积比例。

2.2 保留人物身份与姿态、原始透视、真实光色和场景可信度，允许有明确表达作用的源图一致性发明。它默认沿用原图方向：竖图输出 3:5，横图输出 5:3；高饱和色由构图、情绪和色彩关系决定，不使用固定红/蓝降级；边缘处理根据画面选择，允许完全不出现撕纸效果。仍禁止新增文字和模板装饰。

## 选择版本

| 版本 | 交互方式 | 适合场景 |
| --- | --- | --- |
| 2.2 Skill | 无生成前询问 | 当前推荐；作者化表达、源图方向、无固定照片/插画占比 |
| 2.0 Plugin | MCP Apps 三题单面板，并保留文字降级 | 仍需要可点击 UI 界面 |

2.1 纯文字询问版保留在仓库中作为历史版本，但不再推荐。

## 安装 2.2 Skill（推荐）

2.2 是独立 Skill，不安装 MCP Server。把下面这句话发给 Codex：

```text
Use $skill-installer to install https://github.com/summer95950905-hue/ryan-scenes-plugin/tree/main/skills/ryan-scenes-v2-2
```

也可以在终端安装：

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo summer95950905-hue/ryan-scenes-plugin \
  --path skills/ryan-scenes-v2-2
```

安装后新建一个任务，附上照片并调用 `$ryan-scenes-v2-2`。

## 安装 2.0 Plugin（需要 UI 时）

```bash
codex plugin marketplace add summer95950905-hue/ryan-scenes-plugin
codex plugin add ryan-scenes@ryan-scenes
```

安装后新建一个任务，附上照片并调用 `$ryan-scenes-v2-0`。支持 MCP Apps 的界面会显示三题单面板；其他界面会收到一次性的文字选项。

## 2.2 更新内容

- 完整移除生成前的偏好询问，不再展示 UI 面板或文字选项。
- 移除“自动判断叙事焦点、保留范围与抽象力度”的三项式决策机制。
- 核心定位、创作主线和决策优先级回归 1.3：建立一个源图特定的艺术命题、一个核心情绪或概念张力，以及一个有意义的解释开放点。
- 允许为情绪、关系、节奏、平衡、视线或命题加入有明确作用的源图一致性形式，同时保留人物、透视、真实光色与场景可信度。
- 照片和插画均不设置固定最小、最大或预设面积比例；真实照片可覆盖大部分画面，也可只保留人物、局部水面、建筑群、其他局部或相连碎片。
- 画布方向回归 1.3：竖图默认 3:5，横图默认 5:3，方图或方向不明时使用竖版 3:5；用户指定比例时优先遵守。
- 撕纸边缘回归 1.3 的自适应选择：可用撕纸纤维、灰阶层边、点状消解、不规则标记或自然孤立轮廓；允许完全不使用可见过渡效果。
- 高饱和色回归 1.3 的艺术指导逻辑，根据源图关系、冷暖、互补、明度、构图、情绪和视线选择，不再使用红/蓝固定降级。
- 恢复精确触发词 `单色块模式`：只使用一个连续饱和色场，其他非照片印刷形式统一为中性墨色。
- 继续禁止新增文字、固定模板、无关景物和纯装饰性元素。

## 开发与验证

2.0 Plugin 已提交编译后的 MCP Server 和单文件 UI，因此使用者不需要安装 npm 依赖。修改 2.0 源码时运行：

```bash
cd plugins/ryan-scenes
npm install
npm run build
npm run check
```

2.2 Skill 位于 `skills/ryan-scenes-v2-2/`，不包含运行时依赖。照片不会被 Skill 额外上传、保存或提交到仓库。
